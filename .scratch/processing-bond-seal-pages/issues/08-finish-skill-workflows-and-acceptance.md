# 08 — 完成 Skill 两阶段入口与验收

**What to build:** 让用户能够通过完整的 Skill 说明和两个明确入口执行“生成处理批次”与“接收回章页后回拼”，并用真实底稿样本验证整个流程符合规格。

**Blocked by:** 06 — 生成可筛选的 HTML 处理清单；07 — 完成跨平台前置检查与 macOS 转换。

**Status:** claimed

- [ ] Skill 描述明确说明适用场景、触发语句、输入文件、两个阶段和当前底稿文件范围。
- [ ] 第一阶段入口完成前置检查、Word 转换、处理批次和待盖章页合集生成，并向用户清楚报告结果。
- [ ] 第二阶段入口完成批次校验、文字层或 OCR 识别、标题匹配、日期补齐、原样回拼和 HTML 清单生成。
- [ ] Skill 不把发行文件、印章真伪检查、Word 回写或处理中人工复核描述为已支持能力。
- [ ] Windows 真实样本完成两阶段端到端验收，macOS 转换路径具备可重复的验证步骤。
- [ ] 端到端验收覆盖乱序、缺页、同标题不去重、同标题复用、扫描页、低置信度、部分日期和单文件失败。
- [ ] 所有自动化测试通过，既有表格页识别能力保持可用但不接入当前底稿流程。
- [ ] 最终文档使用领域术语表中的规范名称，并与两份架构决策及正式规格一致。
