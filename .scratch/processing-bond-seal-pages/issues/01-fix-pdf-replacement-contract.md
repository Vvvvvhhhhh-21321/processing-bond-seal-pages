# 01 — 修复 PDF 原样回拼契约与测试基线

**What to build:** 让回拼操作能够删除底稿 PDF 的最后一页，并把回章页作为原始 PDF 页面对象直接插入；同时修复当前测试基线，使后续两阶段开发建立在可靠的 PDF 行为上。

**Blocked by:** None — can start immediately.

**Status:** claimed

- [ ] 修复当前 `pypdf` 版本下测试夹具的字典键类型错误，现有测试全部通过。
- [ ] 当前文页面与回章页尺寸、方向或边界框不同时，前文页面保持不变，回章页保持自身尺寸和方向。
- [ ] 回章页替换过程中不发生缩放、拉伸、裁切或重新栅格化。
- [ ] 空 PDF、非法页码及无法读取的 PDF 返回明确中文错误，不产生损坏的输出文件。
- [ ] 增加不同页面尺寸和方向的回归测试，验证输出页数与页面顺序正确。
