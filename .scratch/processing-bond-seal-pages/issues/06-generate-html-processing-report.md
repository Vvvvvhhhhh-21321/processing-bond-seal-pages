# 06 — 生成可筛选的 HTML 处理清单

**What to build:** 让用户在整个批次完成后获得一个无需联网即可打开的 HTML 处理清单，用于集中核对成功、跳过和失败结果，而不是在处理中逐项暂停确认。

**Blocked by:** 04 — 支持 PP-OCRv6 small 扫描页识别；05 — 在回拼流程中补齐落款日期。

**Status:** ready-for-agent

- [ ] HTML 清单为自包含文件，断网环境下可正常打开、筛选和查看。
- [ ] 每份底稿均有一条结果，包括已处理、低置信度、歧义、未匹配、缺页、转换失败、OCR 失败、日期失败和写入失败。
- [ ] 每条结果显示原底稿、待盖章页合集页码、回章页码、标题、相似度、日期结果、处理状态、原因和输出 PDF 位置。
- [ ] 报告提供按状态筛选和快速定位异常项目的交互能力。
- [ ] 报告包含必要的页面缩略图，缩略图缺失不影响其他内容显示。
- [ ] 报告明确说明系统不检查是否盖章或印章真伪。
- [ ] 重复运行覆盖旧 HTML 和旧生成结果，不保留混杂的过期状态。
- [ ] 自动化测试验证报告数据完整、筛选可用、资源离线和中文路径正确。
