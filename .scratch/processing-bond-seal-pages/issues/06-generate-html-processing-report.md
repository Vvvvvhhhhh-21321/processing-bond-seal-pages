**What to build:** 让用户在整个批次完成后获得一个无需联网即可打开的 HTML 处理清单，用于集中核对成功、跳过和失败结果，而不是在处理中逐项暂停确认。

**Blocked by:** 04 — 支持 PP-OCRv6 small 扫描页识别；05 — 在回拼流程中补齐落款日期。

**Status:** resolved

- [x] HTML 清单为自包含文件，断网环境下可正常打开、筛选和查看。
- [x] 每份底稿均有一条结果，包括已处理、低置信度、歧义、未匹配、缺页、转换失败、OCR 失败、日期失败和写入失败。
- [x] 每条结果显示原底稿、待盖章页合集页码、回章页码、标题、相似度、日期结果、处理状态、原因和输出 PDF 位置。

- [x] 报告不生成页面缩略图，避免额外渲染开销和 HTML 体积；通过本地文件链接直接打开对应 PDF 核对。

- [x] 重复运行覆盖旧 HTML 和旧生成结果，不保留混杂的过期状态。
