# 02 — 从 Windows Word 生成处理批次

**What to build:** 让 Windows 用户可以把一批 `.doc` 和 `.docx` 底稿文件转换为完整 PDF，逐份提取最后一页并生成待盖章页合集，同时保存第二阶段所需的处理批次信息。

**Blocked by:** 01 — 修复 PDF 原样回拼契约与测试基线。

**Status:** ready-for-agent

- [ ] Windows 上通过本机 Microsoft Word 后台转换 `.doc` 与 `.docx`，不显示窗口、不保存或修改原 Word。
- [ ] 每份成功转换的底稿保留完整 PDF，并将最后一页逐份加入待盖章页合集。
- [ ] 同标题底稿不去重，待盖章页合集页数与成功处理的底稿数量一致。
- [ ] 处理批次记录源文件标识、相对位置、标题、合集页码、完整 PDF 页数和文件校验值。
- [ ] 单个文件转换、读取或提取失败时记录失败并继续处理其他文件。
- [ ] 重复运行可覆盖同一位置的旧生成结果，但原 Word 始终保持不变。
- [ ] 端到端测试覆盖成功文件、重复标题文件和转换失败文件混合存在的批次。
