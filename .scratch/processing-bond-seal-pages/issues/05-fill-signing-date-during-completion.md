# 05 — 在回拼流程中补齐落款日期

**What to build:** 让用户在第二阶段提供统一落款日期，系统在不覆盖已有内容的前提下补齐回章页缺失的年、月、日，并把日期结果纳入批次状态。

**Blocked by:** 03 — 完成文字层回章页的自动回拼。

**Status:** claimed

- [ ] 统一落款日期为可选输入；未提供时不进行日期写入。
- [ ] 页面已有的年、月或日保持原值，只补齐缺失的组成部分。
- [ ] 新增日期与页面已有内容发生碰撞时按既定最小字号范围尝试安全落位。
- [ ] 无法安全落位的日期组成部分不写入，并记录具体失败原因。
- [ ] 日期补齐失败不阻止已匹配回章页完成回拼，也不阻止其他文件处理。
- [ ] 日期写入不改变印章、原有文字和页面尺寸。
- [ ] 测试覆盖全部空白、部分已有、全部已有、碰撞缩小和无法落位场景。
