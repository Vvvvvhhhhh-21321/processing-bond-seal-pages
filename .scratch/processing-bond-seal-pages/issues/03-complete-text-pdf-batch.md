# 03 — 完成文字层回章页的自动回拼

**What to build:** 让用户把含文字层、可能乱序或缺页的回章页合集交给已有处理批次，高置信度页面自动回拼为完整盖章版 PDF，其余项目跳过但整批继续。

**Blocked by:** 02 — 从 Windows Word 生成处理批次。

**Status:** ready-for-agent

- [ ] 第二阶段读取处理批次中的完整底稿 PDF 和映射，不重新转换原 Word。
- [ ] 开始回拼前校验批次文件及校验值，单个损坏或不一致项目不影响其他项目。
- [ ] 回章页顺序不影响匹配，缺页只使对应底稿保持未处理状态。
- [ ] 标题优先读取书名号内容，没有书名号时可读取主要标题并用原文件名辅助校验。
- [ ] 标题经过 Unicode、空白和标点归一化，相似度不低于 90 才自动回拼。
- [ ] 低置信度、候选歧义、无标题及未匹配页面不按顺序猜测，也不中断整个批次。
- [ ] 同标题页面优先逐页配对；回章页数量不足时允许复用已匹配的同标题页面。
- [ ] 成功项目使用原始回章页直接替换最后一页并输出完整盖章版 PDF。
- [ ] 测试覆盖乱序、缺页、同标题数量一致与不足、低置信度和无标题场景。
