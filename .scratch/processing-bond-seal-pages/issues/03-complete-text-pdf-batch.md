# 03 — 完成文字层回章页的自动回拼

**What to build:** 让用户把含文字层、可能乱序或缺页的回章页合集交给已有处理批次，高置信度页面自动回拼为完整盖章版 PDF，其余项目跳过但整批继续。

**Blocked by:** 02 — 从 Windows Word 生成处理批次。

**Status:** resolved

- [x] 第二阶段读取处理批次中的完整底稿 PDF 和映射，不重新转换原 Word。
- [x] 开始回拼前校验批次文件及校验值，单个损坏或不一致项目不影响其他项目。
- [x] 回章页顺序不影响匹配，缺页只使对应底稿保持未处理状态。
- [x] 标题优先读取书名号内容，没有书名号时可读取主要标题并用原文件名辅助校验。
- [x] 标题经过 Unicode、空白和标点归一化，相似度不低于 90 才自动回拼。
- [x] 低置信度、候选歧义、无标题及未匹配页面不按顺序猜测，也不中断整个批次。
- [x] 同标题页面优先逐页配对；回章页数量不足时允许复用已匹配的同标题页面。
- [x] 成功项目使用原始回章页直接替换最后一页并输出完整盖章版 PDF。
- [x] 测试覆盖乱序、缺页、同标题数量一致与不足、低置信度和无标题场景。

## Answer

已实现“处理批次 + 含文字层的回章页合集 → 完整盖章版 PDF”的公开入口。第二阶段只读取第一阶段产物，按标题确定性匹配乱序页面；90 分以下、歧义、无标题或缺页项目保留可检查状态并跳过，其他项目继续。相同标题优先逐页分配，数量不足时才复用；成功项目直接用原始回章页替换完整底稿文件的最后一页，保留页面尺寸。

批次校验覆盖 PDF 哈希、可读性、页数、标题映射及重复的底稿文件标识、输出相对位置和完整 PDF 路径；所有冲突记录都会隔离，避免互相覆盖或串用正文。

实现提交：`551d024`、`77f3ea8`、`bec74b6`、`80de2c7`。完整测试共 54 项：53 项通过；1 项真实 Word 冒烟测试按既有前置条件跳过。标准与规格双轴复核均无剩余阻断发现。
